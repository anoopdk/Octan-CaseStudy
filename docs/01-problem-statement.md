# Problem statement

## Client context

- **Delivery organisation:** Zynx Technologies Ltd
- **Domain client:** Energy & Industrial Client
- **Engagement type:** Solution Design / Case Delivery

## Business problem

The Energy & Industrial Client (Octan scenario) needed a scalable data platform that could ingest IoT plant sensors, Excel project reports, OAuth-protected SaaS APIs, and sensitive on-prem financial data, while enabling autonomous analytics under strong access control.

## Success criteria (engagement)

- Clear architecture and ownership model
- Inspectable artefacts in Git (docs, diagrams, code/notebooks)
- Domain-safe documentation suitable for public portfolio audit
- Handover path for client engineering teams
